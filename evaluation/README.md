# 错因诊断评测说明

## 评测集

- 样例数：60 条自建标注样例（`2026-08-25-v2`），不代表真实用户数据。
- 覆盖学段：小学五、六年级；初一至初三；高一至高三。
- 覆盖学科：数学、语文、英语、物理、化学、生物。
- 覆盖标签：知识盲区、题型不熟、计算粗心、状态差、态度问题；状态标签为正常、疲惫、敷衍。

## 已验证结果

评测时间：2026-08-16

| 指标 | 结果 |
| --- | --- |
| 数据集 / Prompt | `2026-08-25-v2` / `v2.1-error-boundary` |
| 结构化输出有效率 | 60/60（100%） |
| 错因分类命中率 | 55/60（91.7%） |
| 状态识别命中率 | 59/60（98.3%） |
| 平均端到端耗时 | 4.07 秒 |

仍有 5 条错因标签不一致、1 条状态标签不一致；主要是“知识盲区 / 题型不熟”边界与“赶时间 / 疲惫”边界。它们保留在报告中，作为人工复核与后续二级标签设计的输入，而非为了提升分数强行改标。

完整的 Prompt 迭代与同集对照见 [`prompt-iteration.md`](./prompt-iteration.md)。

## 复核方式

本地启动后端后运行 `npm run evaluate`，会调用与前端相同的诊断接口并更新 `latest-report.json`。如需调用线上环境，可通过 `EVALUATION_API_URL` 显式指定。

每次运行会生成 `evaluationRunId`，并将以下元数据写入 Langfuse Trace：

- `evaluationCaseId`：对应单条标注样例；
- `evaluationRunId`：对应一次完整复跑；
- `evaluationDatasetVersion`：区分 24 条旧集和 60 条扩展集；
- `promptVersion`：对应服务端 Prompt 版本。

`latest-report.json` 会输出总命中率，并按错因、状态、学段拆分。比较 Prompt 时应固定同一数据集版本，只比较不同 `evaluationRunId` 的报告；不要把不同数据集的分数直接当作 Prompt 优劣。
